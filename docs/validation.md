## 验证重点

- 批准修改/撤销后，召回和回答能否保持一致。
- 展示片段截断时，能否仍从完整窗口核验支持原句。
- 待审、hash 不符、引用缺失和对象错配能否正确限制输出。
- 检索不可用时是否明确降级，而非隐藏失败。
- 目标关联路径能否逐边追溯，且不把关联转换成治疗结论。
- 目标多 Agent 流程是否实际产生委派、工具反馈及有界修订。
