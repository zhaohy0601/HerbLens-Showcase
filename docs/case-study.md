# 两项功能的交互示意

**本页是产品流程说明，不是运行截图、已完成实验或真实 Agent 执行记录。** 没有在此给出未经核实的医学结论。

## 场景一：健康说法核验

用户示例：“某植物提取物的研究，能够支持普通食品的宣传说法吗？”

预期流程：

1. 明确用户所指食品、成分、提取物或制剂形式。
2. 检索相关材料，保留出处与研究对象。
3. 区分人体、动物与体外研究，以及材料是否匹配。
4. 仅在允许范围内形成回答；来源不足时明确缺口。
5. 展示支持原句、适用限制和引用。

已有核验原型具备上述部分基础能力和隔离验证记录；具体真实批准范围及新版完整验收仍待确认。不能用这份示意代替真实演示。

## 场景二：食物—成分—健康研究关联探索

用户示例：“这个植物食品涉及哪些成分？可以查看相关研究吗？”

目标流程：

1. 解析实体并处理同名、别名与材料形态歧义。
2. 查询实际存在的食物—成分记录。
3. 根据用户选择查询成分相关研究记录。
4. 逐段展示关系类型、来源与适用限定。
5. 没有关系记录时显示未覆盖，不让模型补造路径。

这一能力处于升级规划中。真实关系数据覆盖和端到端功能未在本展示版本验收，不提供虚构路径或拟造引用。
